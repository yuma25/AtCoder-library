# 競技プログラミング：コンテナ選択ガイド

競技プログラミング（AtCoderなどのコンテスト）で頻出する「典型問題」を例に、それぞれのコンテナがどのような場面で活躍するのかを具体的に紹介します。

---

## 1. シーケンス系（データを並べる）

| コンテナ | 特徴 | 典型問題例・使い方 |
| :--- | :--- | :--- |
| **`vector`** | **動的配列**。ランダムアクセスが最速 ($O(1)$)。 | 「$N$ 人のテストの点数が与えられます。上位 $K$ 人の合計点数を求めてください」<br>点数を `vector` にすべて入れ、降順にソートして先頭から $K$ 個足し合わせます。最も基本となるデータの持ち場です。 |
| **`deque`** | **両端キュー**。先頭・末尾の両端で追加・削除が $O(1)$。 | 「01-BFS（重み0と1の辺しかないグラフの最短距離）」<br>普通の道（コスト1）を通る時は末尾に追加し、ワープゾーン（コスト0）を通る時は**先頭に追加**することで、常にコストが小さい順に探索できます。 |
| **`string`** | **文字列**。文字の配列。 | 「与えられた文字列が回文か判定してください」または「100桁の数字同士の足し算をしてください」<br>`reverse()` で反転させて一致するか確かめたり、巨大な数字（`long long` に収まらない数）を文字として1桁ずつ処理したりします。 |

---

## 2. 集合・連想配列系（検索とカウント）

| コンテナ | 特徴 | 典型問題例・使い方 |
| :--- | :--- | :--- |
| **`set`** | **順序付き集合**。重複を許さず、常にソート状態。 | 「$N$ 回ガチャを引いて、IDが $A_1, A_2, \dots, A_N$ のキャラが出ました。全部で何種類のキャラを手に入れましたか？」<br>当たったIDをすべて `set` に `insert` します。重複は自動で無視されるため、最終的な `set` のサイズを出力するだけで正解になります。 |
| **`map`** | **連想配列**。キーと値を紐付け。 | 「$N$ 枚の投票用紙があります。最も多く書かれていた人の名前を答えてください」<br>`map<string, int> mp;` を用意し、読み込んだ名前 `s` に対して `mp[s]++` とします。文字列をインデックスの代わりにできるため、集計が極めて簡単です。 |
| **`multiset`** | **重複許容集合**。重複を許しつつ、常にソート状態。 | 「データが次々に追加・削除されます。現在の最大値と最小値の差を常に求めてください」<br>値の追加・削除を行いながら、常にソートされた状態を保ちます（`*mst.rbegin() - *mst.begin()` で最大値と最小値の差が一瞬で計算できます）。 |

## 3. コンテナアダプタ（探索用ツール）

| コンテナ | 特徴 | 典型問題例・使い方 |
| :--- | :--- | :--- |
| **`stack`** | **LIFO**（後入れ先出し）。 | 「括弧の列 `()(())` の対応が正しく閉じているか判定してください」<br>`(` が来たらスタックに入れ、`)` が来たら取り出します。途中で空になったり最後に残ったりしたら不正解、という判定に使います。 |
| **`queue`** | **FIFO**（先入れ先出し）。 | 「迷路のスタートからゴールまでの最短手数を求めてください」<br>**幅優先探索（BFS）**の必須ツールです。今いる場所から「1歩で行けるマス」を末尾に追加し、先頭から順番に取り出して探索を進めます。 |
| **`priority_queue`** | **優先度付きキュー**。常に最大/最小を取り出す。 | 「街を繋ぐ道路があり、街Aから街Bまでの最短経路を求めてください」<br>**ダイクストラ法**で使います。「現在わかっている中で、一番スタートから近い街」を常に取り出し続ける必要があるため、自動でトップに値が来るこのコンテナを使います。 |

---

## 4. 特殊・ユーティリティ

| コンテナ | 特徴 | 典型問題例・使い方 |
| :--- | :--- | :--- |
| **`bitset`** | **ビット管理**。高速なビット演算。 | 「$N$ 個の品物からいくつか選んで、重さの合計をぴったり $K$ にできますか？」<br>**部分和問題**です。「作れる重さ」をビットで管理し、シフト演算（`<<`）で一気に更新することで、通常の配列より約64倍高速になります。 |
| **`pair` / `tuple`** | **組**。複数の値をまとめる。 | 「$N$ 個のイベントがあり、参加できる最大数を求めてください」<br>**区間スケジューリング問題**です。終了時間と開始時間を `pair` に入れてソートすると「終了時間が早い順」に並ぶため、貪欲法で解けます。 |

## 💡 具体的な宣言と初期化（逆引き）

### vector (動的配列)
```cpp
// 1次元配列: サイズNを0で初期化
vector<int> v(N, 0);

// 2次元配列: H行W列を0で初期化
vector<vector<int>> v(H, vector<int>(W, 0));
```

### priority_queue (優先度付きキュー)
```cpp
// 最大値を取り出す（デフォルト）
priority_queue<int> pq;

// 最小値を取り出す（昇順）
priority_queue<int, vector<int>, greater<int>> pq;
```

### map / set
```cpp
// 集計
map<string, int> mp;
mp["apple"]++;

// 存在判定
set<int> st;
if (st.count(x)) { ... } // または st.contains(x) ※C++20
```
