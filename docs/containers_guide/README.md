# 競技プログラミング：コンテナ選択ガイド

競技プログラミング（AtCoderなどのコンテスト）で頻出する「典型問題」を例に、それぞれのコンテナがどのような場面で活躍するのかを具体的に紹介します。

---

### 1. シーケンス系（データを並べる）

* **`vector` (動的配列)**
    * **問題例:** 「$N$ 人のテストの点数が与えられます。上位 $K$ 人の合計点数を求めてください」
    * **使い方:** 点数を `vector` にすべて入れ、降順にソート（並び替え）して先頭から $K$ 個足し合わせます。最も基本となるデータの持ち場です。

* **`deque` (両端キュー)**
    * **問題例:** 「01-BFS（重み0と1の辺しかないグラフの最短距離）」
    * **使い方:** 普通の道（コスト1）を通る時は末尾に追加し、ワープゾーン（コスト0）を通る時は**先頭に追加**することで、常にコストが小さい順に探索できます。

* **`string` (文字列)**
    * **問題例:** 「与えられた文字列が回文（上から読んでも下から読んでも同じ）か判定してください」または「100桁の数字同士の足し算をしてください」
    * **使い方:** `reverse()` で反転させて一致するか確かめたり、巨大な数字（`long long` に収まらない数）を文字として1桁ずつ処理したりします。

---

### 2. 集合・連想配列系（検索とカウント）

* **`set` (順序付き集合)**
    * **問題例:** 「$N$ 回ガチャを引いて、IDが $A_1, A_2, \dots, A_N$ のキャラが出ました。全部で何種類のキャラを手に入れましたか？」
    * **使い方:** 当たったIDをすべて `set` に `insert` します。重複は自動で無視されるため、最終的な `set` のサイズ（要素数）を出力するだけで正解になります。

* **`map` (連想配列)**
    * **問題例:** 「$N$ 枚の投票用紙があります。最も多く書かれていた人の名前を答えてください」
    * **使い方:** `map<string, int> mp;` を用意し、読み込んだ名前 `s` に対して `mp[s]++` とします。文字列をインデックスの代わりにできるため、集計が極めて簡単です。

* **`multiset` (重複許容の順序付き集合)**
    * **問題例:** 「データが次々に追加されます。また、指定されたデータが途中で削除されることもあります。現在の最大値と最小値の差を常に求めてください」
    * **使い方:** 値の追加・削除を行いながら、常にソートされた状態を保ちます（`*mst.rbegin() - *mst.begin()` で最大値と最小値の差が一瞬で計算できます）。

---

### 3. コンテナアダプタ（探索用ツール）

* **`stack` (後入れ先出し)**
    * **問題例:** 「`()(())` のような括弧の列が与えられます。括弧の対応が正しく閉じているか判定してください」
    * **使い方:** `(` が来たらスタックに入れ、`)` が来たらスタックから取り出します。途中でスタックが空になったり、最後に中身が残っていたら不正解、という判定に使います。

* **`queue` (先入れ先出し)**
    * **問題例:** 「迷路のスタートからゴールまでの最短手数を求めてください」
    * **使い方:** 幅優先探索（BFS）の必須ツールです。今いる場所から「1歩で行けるマス」をキューの末尾にどんどん追加し、先頭から順番に取り出して探索を進めます。

* **`priority_queue` (優先度付きキュー)**
    * **問題例:** 「複数の街と、街を結ぶ道路（長さがバラバラ）があります。街Aから街Bまでの最短経路を求めてください」
    * **使い方:** ダイクストラ法というアルゴリズムで使います。「現在わかっている中で、一番スタートから近い街」を常に取り出し続ける必要があるため、自動で最小値がトップに来るこのコンテナを使います。

---

### 4. 特殊・ユーティリティ

* **`bitset` (ビット管理)**
    * **問題例:** 「$N$ 個の品物（重さ $W_i$）があります。いくつか選んで、重さの合計をぴったり $K$ にすることはできますか？」
    * **使い方:** 部分和問題と呼ばれる問題です。`bitset` を使って「作れる重さ」のフラグを管理し、シフト演算（`<<`）を使って一気に計算を更新することで、通常の配列を使うより実行速度が約64倍になります。

* **`pair` / `tuple` (組)**
    * **問題例:** 「$N$ 個のイベントがあり、それぞれ開始時間と終了時間が決まっています。できるだけ多くのイベントに参加するにはどう選べばいいですか？」
    * **使い方:** 区間スケジューリング問題です。終了時間と開始時間を `pair<int, int>` にまとめて `vector` に入れます。ソートすると「終了時間が早い順」に綺麗に並ぶため、貪欲に選んでいくだけで解けるようになります。

## 💡 具体的な宣言と初期化（逆引き）

### vector (動的配列)
```cpp
// 1次元配列: サイズNを0で初期化
vector<int> v(N, 0);

// 2次元配列: H行W列を0で初期化
vector<vector<int>> v(H, vector<int>(W, 0));
```

### priority_queue (優先度付きキュー)
```cpp
// 最大値を取り出す（デフォルト）
priority_queue<int> pq;

// 最小値を取り出す（昇順）
priority_queue<int, vector<int>, greater<int>> pq;
```

### map / set
```cpp
// 集計
map<string, int> mp;
mp["apple"]++;

// 存在判定
set<int> st;
if (st.count(x)) { ... } // または st.contains(x) ※C++20
```
