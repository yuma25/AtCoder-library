## 1. ライブラリのインポート

```python
import sys
import math
import bisect
import itertools
import collections
import heapq
```
- **`sys`**: 標準入出力や再帰上限の設定に使います。
- **`math`**: GCD（最大公約数）や数学定数に使います。
- **`bisect`**: ソート済みリストに対する二分探索に使います。
- **`itertools`**: 順列・組合せの列挙に使います。
- **`collections`**: `deque`（高速な先頭削除）や `defaultdict` に使います。
- **`heapq`**: 優先度付きキュー（最小値を高速に取り出す）に使います。

## 2. Python 固有の必須設定

```python
sys.setrecursionlimit(10**7)
```
- **処理**: 再帰関数の深さの上限を引き上げます。
- **重要性**: Python のデフォルトは 1000 程度と非常に浅いため、深さ優先探索（DFS）などでエラーになるのを防ぐために必須です。

## 3. 定数 (Constants)

- **`INF = 10**18`**: 「無限大」として扱う非常に大きな数。
- **`MOD = 998244353`**: AtCoder で最も一般的な余りの法。
- **`dx, dy`**: グリッド探索（上下左右・斜め）用の移動方向配列。

---

## 4. 入出力高速化

Python の標準的な `input()` は非常に遅いため、以下の関数を使います。

- **`input = lambda: sys.stdin.readline().rstrip()`**: 高速な一行読み込み。
- **`I()`**: 【戻り値: int】 整数を 1 つ読み込みます。
- **`MI()`**: 【戻り値: iterator】 複数の整数を読み込みます。 `A, B = MI()` のように使います。
- **`LI()`**: 【戻り値: list】 数列を一括でリストとして読み込みます。 `A = LI()` のように使います。

---

## 5. 便利関数 (`chmax`, `chmin`)

Python では変数が「値渡し」のような挙動をするため、C++ と使い方が異なります。

### `chmax(a, b)` / `chmin(a, b)`
- **引数**: `a` (既存の値), `b` (新しい値)
- **戻り値**: 比較して大きい（または小さい）方の値。
- **使い方**: `ans = chmax(ans, new_val)` のように、**戻り値で上書き**して使います。

## 6. 組合せ計算 (`Combination` クラス)

```python
comb = Combination(200000)
res = comb.nCr(10, 3)
```
- **初期化 (__init__)**: 【引数: n (最大値)】 $O(N)$ で階乗のテーブルを作成します。
- **`nCr(n, r)`**: 【引数: n, r, 戻り値: int】 $nCr \pmod{MOD}$ を $O(1)$ で計算します。

## 7. Python 標準ライブラリ操作リファレンス

ファイル末尾のチートシートのポイントです。

### [1] リスト (list) / 文字列 (str)
- **`A.append(x)`**: 【引数:要素, 戻り値:None】 末尾に追加。
- **`A.pop()`**: 【引数:無, 戻り値:要素】 末尾を取り出して削除。
- **`A[pos:pos+len]`**: スライス。部分文字列や部分リストを取得。

### [2] デック (deque)
- **`dq.appendleft(x)` / `dq.popleft()`**: 【計算量: $O(1)$】 先頭への追加・削除。**通常のリストの `pop(0)` は $O(N)$ かかるため、先頭を消すなら必ずこれを使います。**

### [3] 辞書 (dict) / 集合 (set)
- **`x in S`**: 【計算量: $O(1)$】 存在判定。非常に高速です。
- **`D.get(k, 0)`**: 【引数:キー, デフォルト値】 キーがなくてもエラーにならず、デフォルト値を返す安全なアクセス方法。

### [4] 優先度付きキュー (heapq)
- **`heapq.heappush(hq, x)`**: 【計算量: $O(\log N)$】 要素の追加。
- **`heapq.heappop(hq)`**: 【計算量: $O(\log N)$】 **最小値**の取り出し。
  - **注意**: 最大値を取り出したい場合は、値を `-1` 倍して格納するのが定石です。

### [5] 二分探索 (bisect)
- **`bisect.bisect_left(A, x)`**: 【戻り値: int】 ソート済みリスト `A` に対して、`x` 以上の最初の要素のインデックスを返します（C++ の `lower_bound` 相当）。

### [6] 順列・組合せ (itertools)
- **`itertools.permutations(A)`**: 全順列を生成します。ループで回して使います。

### [7] 数学 (math) / その他
- **`math.gcd(a, b) / math.lcm(a, b)`**: 最大公約数・最小公倍数。
- **`sum(A) / max(A) / min(A)`**: 合計・最大・最小。
- **`collections.Counter(A)`**: 要素の出現回数を数える最強ツール。

## 8. 実践的なヒント

### 再帰上限の注意点
`sys.setrecursionlimit(10**7)` を設定していますが、メモリ制限（MLE）が厳しい問題では、再帰が深すぎるとスタックオーバーフローで落ちる場合があります。その場合は、`deque` を使ったループ（非再帰）による探索への書き換えを検討してください。

### 入出力の使い分け
- 数列の読み込み: `A = LI()`
- $N$ 行にわたる整数の読み込み: `A = [I() for _ in range(N)]`
- $N$ 行 $M$ 列の行列読み込み: `B = [LI() for _ in range(N)]`
