## 3. 座標圧縮
### 【概要】
非常に大きな数値範囲（例：$0 \sim 10^9$）を、要素間の大小関係を維持したまま、小さな数値範囲（$0 \sim N$）に変換します。

### 【実装の流れ (C++)】
```cpp
vi b = a;
sort(all(b));
b.erase(unique(all(b)), b.end());
rep(i, n) {
    a[i] = lower_bound(all(b), a[i]) - b.begin();
}
```

## 4. 半分全列挙
### 【概要】
要素数 $N$ の全列挙が $2^N$ で間に合わないとき、$N/2$ ずつに分けて全列挙し、後でそれらを効率よく（二分探索等で）組み合わせます。計算量を $O(2^{N/2} \cdot N)$ 程度に落とせます。
