# データ構造 (Data Structures)

## 1. セグメント木 (Segment Tree)
### 【概要】
配列の「1要素更新」と「区間クエリ（最小値、合計など）」を両方 $O(\log N)$ で行います。

### 【使いどころ】
- RMQ (Range Minimum Query): 区間の最小値を取得。
- 動的な区間加算や更新が必要な問題。

---

## 2. Binary Indexed Tree (BIT / Fenwick Tree)
### 【概要】
「1要素への加算」と「先頭からの累積和」を $O(\log N)$ で行います。セグメント木より実装が簡単で高速です。

### 【使いどころ】
- 転倒数（反転数）の計算。
- 平面走査などのテクニックと組み合わせて。
