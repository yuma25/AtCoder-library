## ⚡ 基本ワークフロー (クイックコマンド)
コンテスト中に最も頻繁に使用するコマンドである．

### 1. 問題の取得
```bash
# ABCディレクトリへ移動
cd ABC

# 例: ABC350 の全問題をダウンロード
acc new abc350
cd abc350/a
```

### 2. サンプルテスト
```bash
# 自動でコンパイルしてサンプルケースを検証 (エイリアス設定済み)
atest
```

### 3. コードの提出
```bash
# テストが通ればそのまま提出
acc submit
```
