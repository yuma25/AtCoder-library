# AtCoder 完全自動化環境 構築ガイド (WSL2/Linux)

このガイドでは，テンプレートと自動化ツールを連携させ，競技プログラミングの効率を最大化する環境を構築する．
初心者でも迷わずに進められるよう，コマンドを貼り付けるだけで設定が完了する構成としている．

---

## 1. 必須ツールのインストール

ターミナル（WSL2のUbuntu等）を開き，以下のコマンドをコピー＆ペーストして実行し，自動化に必要なツールをインストールする．

```bash
# サンプルテスト・自動提出ツールのインストール
pip install online-judge-tools setuptools

# コンテスト管理ツールのインストール（Node.js環境が必要）
npm install -g atcoder-cli
```

---

## 2. ログイン設定 (Cloudflare回避)

現在，Cloudflareのアクセス制限により，コマンドからの直接ログインが失敗することがある．そのため，ブラウザのログインセッション情報（Cookie）を手動で設定して連携させる．

### ① ブラウザで `REVEL_SESSION` を取得する
1. 普段使用しているブラウザで [AtCoder](https://atcoder.jp) にログインする．
2. ログインした状態で `F12` キー（Macの場合は `Command + Option + I`）を押し，デベロッパーツールを開く．
3. デベロッパーツールの上部タブから「アプリケーション」（Firefoxの場合は「ストレージ」，Chromeの英語表記の場合は「Application」）を選択する．
4. 左メニューの「Cookie」から「https://atcoder.jp」をクリックする．
5. 一覧から **`REVEL_SESSION`** を探し，その「値」（ランダムな長い英数字の文字列）をコピーする．

### ② コピペ用設定コマンドの実行
WSL2のターミナルを開き，以下のコマンドを実行する．その際，`YOUR_VALUE` の部分を，先ほどコピーした `REVEL_SESSION` の値に書き換えること．

```bash
# 設定用フォルダの作成
mkdir -p ~/.config/atcoder-cli-nodejs

# セッション情報の書き込み（YOUR_VALUE部分を書き換えて実行すること）
cat << EOF > ~/.config/atcoder-cli-nodejs/session.json
{
  "cookies": [
    "REVEL_SESSION=YOUR_VALUE"
  ]
}
EOF
```

### ③ ログイン情報の同期
以下のコマンドを1行ずつ実行し，正しくログインできているか確認する．

```bash
acc login
```
※既に設定が反映されていれば，ログイン確認に成功する．

次に，テストツール（`oj`）にログイン状態を確認させる．
```bash
oj login --check https://atcoder.jp/
```
ターミナルに `SUCCESS: You have already signed in.` と表示されれば，ログイン設定は完了である．

## 3. テンプレートの自動展開設定

`acc new` コマンドを実行した際，問題ごとに `Template.cpp` などのひな形ファイルが自動的にコピーされ，テストが実行できるように設定する．

### ① 設定用フォルダの作成とテンプレートのコピー
ターミナルで以下のコマンドを実行する．絶対パスを使用しているため，どのフォルダから実行しても正常に動作する．

```bash
# 設定を格納するフォルダの作成
mkdir -p ~/.config/atcoder-cli-nodejs/cpp
mkdir -p ~/.config/atcoder-cli-nodejs/python

# テンプレートファイルを自動化設定フォルダへコピー
cp ~/github/atcoder-library/templates/Template.cpp ~/.config/atcoder-cli-nodejs/cpp/main.cpp
cp ~/github/atcoder-library/templates/Template.py ~/.config/atcoder-cli-nodejs/python/main.py
```

### ② 設定ファイル (`template.json`) の作成
以下のコマンドをそのままターミナルに貼り付けて実行し，自動テストと自動提出のルールを設定する．

**C++用の設定ファイル作成:**
```bash
cat << 'EOF' > ~/.config/atcoder-cli-nodejs/cpp/template.json
{
  "task": {
    "program": "main.cpp",
    "submit": "main.cpp",
    "test": "g++ -std=c++20 -O2 -Wall -Wextra -DLOCAL main.cpp -o a.out && ./a.out"
  }
}
EOF
```

**Python用の設定ファイル作成:**
```bash
cat << 'EOF' > ~/.config/atcoder-cli-nodejs/python/template.json
{
  "task": {
    "program": "main.py",
    "submit": "main.py",
    "test": "python3 main.py"
  }
}
EOF
```

### ③ デフォルトテンプレートの設定
日常的に使用する言語（ここではC++）をデフォルトに設定する．
```bash
acc config default-template cpp
```

## 4. 便利機能の設定 (エイリアス)

毎回長いテストコマンドを打つ手間を省くため，簡単な短いコマンド（エイリアス）を登録する．

### ① エイリアスの登録コマンド
以下のコマンドをそのままターミナルで実行し，設定ファイル（`.bashrc`）の末尾にテスト用のショートカットコマンドを書き加える．

```bash
cat << 'EOF' >> ~/.bashrc

# AtCoder 自動テスト用ショートカット
alias atest='g++ -std=c++20 -O2 -Wall -Wextra -DLOCAL main.cpp -o a.out && oj t -c ./a.out -d tests/'
alias atest-py='oj t -c "python3 main.py" -d tests/'
EOF
```

### ② 設定の即時反映
書き換えた設定を，現在のターミナルに反映させる．
```bash
source ~/.bashrc
```

これで環境構築はすべて完了である．
次に，どのようにコンテストでこの環境を使用するかを学ぶため，**[使い方ガイド](使い方ガイド.md)** へ進むこと．
