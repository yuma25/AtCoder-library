# AtCoder 完全自動化環境 構築ガイド (WSL2/Linux)

このガイドでは、最強のテンプレートと自動化ツールを連携させ、競技プログラミングの効率を最大化する環境を構築します。

---

## 1. 必須ツールのインストール

ターミナルを開き、以下の 2 つのツールをインストールしてください。

```bash
# サンプルテスト・自動提出ツール
pip install online-judge-tools setuptools

# コンテスト管理ツール
npm install -g atcoder-cli
```

---

## 2. ログイン設定 (Cloudflare回避)

現在、Cloudflareの制限により、通常のログインコマンドが失敗することがあります。その場合は、ブラウザのセッション情報（Cookie）を手動で設定します。

### ① ブラウザで `REVEL_SESSION` を取得
1. ブラウザで [AtCoder](https://atcoder.jp) にログイン。
2. `F12` キーでデベロッパーツールを開き、「アプリケーション」→「Cookie」→「https://atcoder.jp」を選択。
3. **`REVEL_SESSION`** の値をコピー。

### ② atcoder-cli (acc) の設定
WSL2のターミナルで以下を実行（`YOUR_VALUE` をコピーした値に書き換えてください）。

```bash
mkdir -p ~/.config/atcoder-cli-nodejs
cat << EOF > ~/.config/atcoder-cli-nodejs/session.json
{
  "cookies": [
    "REVEL_SESSION=YOUR_VALUE"
  ]
}
EOF
```

### ③ online-judge-tools (oj) の設定
以下のコマンドを実行して `oj` にログイン情報を同期させます。

```bash
acc login
oj login --check https://atcoder.jp/
```
`SUCCESS: You have already signed in.` と表示されれば完了です。

## 3. テンプレートの自動展開設定

`acc new` コマンドで問題フォルダを作成した際、テンプレートが自動的にコピーされるように設定します。

### 設定フォルダの構築
```bash
# ディレクトリ作成
mkdir -p ~/.config/atcoder-cli-nodejs/cpp
mkdir -p ~/.config/atcoder-cli-nodejs/python

# テンプレートファイルのコピー (プロジェクトルートで実行)
cp templates/Template.cpp ~/.config/atcoder-cli-nodejs/cpp/main.cpp
cp templates/Template.py ~/.config/atcoder-cli-nodejs/python/main.py
```

### `template.json` の作成
以下の内容でファイルを作成します。

**C++用 (`~/.config/atcoder-cli-nodejs/cpp/template.json`):**
```json
{
  "task": {
    "program": "main.cpp",
    "submit": "main.cpp",
    "test": "g++ -std=c++20 -O2 -Wall -Wextra -DLOCAL main.cpp -o a.out && ./a.out"
  }
}
```

**Python用 (`~/.config/atcoder-cli-nodejs/python/template.json`):**
```json
{
  "task": {
    "program": "main.py",
    "submit": "main.py",
    "test": "python3 main.py"
  }
}
```

### デフォルトテンプレートの設定
```bash
acc config default-template cpp
```

## 4. 便利機能の設定 (エイリアス)

テストを簡単にするため、`.bashrc` にエイリアスを追加します。

```bash
# ~/.bashrc の末尾に追記
cat << 'EOF' >> ~/.bashrc

# AtCoder Testing Aliases
alias atest='g++ -std=c++20 -O2 -Wall -Wextra -DLOCAL main.cpp -o a.out && oj t -c ./a.out -d tests/'
alias atest-py='oj t -c "python3 main.py" -d tests/'
EOF

# 設定の反映
source ~/.bashrc
```

## 5. 実戦ワークフロー

### ① 問題のダウンロード
```bash
acc new abcXXX  # abc350 など
cd abcXXX/a
```

### ② 実装
VS Code で `main.cpp` を開き、コードを書きます。

### ③ 自動テスト
```bash
# C++の場合
atest

# Pythonの場合
atest-py
```

### ④ 提出
```bash
acc submit
```
