# C++ 最強スニペット解説 (cp)

このドキュメントでは、`snippets/CPPスニペット.json` に登録されている `cp` スニペットの詳細と、競技プログラミングにおける鉄則を解説します。

## 1. テンプレートの構成
展開されるコードは大きく分けて以下の構成になっています。
- **型エイリアス**: `ll` (long long), `vi` (vector<int>) 等の短縮。
- **定数**: `INF`, `MOD` (998244353), `dx/dy` (グリッド移動)。
- **便利マクロ**: `rep(i, n)` (0からn-1), `all(v)` (v.begin, v.end) 等。
- **入出力高速化**: `FastIO` による `cin/cout` の高速化と、浮動小数点の精度設定。
- **便利関数**: `chmax`, `chmin` (値を更新しつつ成否を返す)。
- **入出力オーバーロード**: `pair` や `vector` を直接 `cin/cout` できる拡張。
- **数学ライブラリ**: `pow_mod`, `inv_mod`, `Combination` (nCr)。

## 2. 競技プログラミングの鉄則・チートシート
スニペットの下部には、標準ライブラリ（STL）の膨大なチートシートが含まれています。

### [1] シーケンス系 (vector, deque, string)
- **鉄則**: `reserve(n)` を使うことで、大量の `push_back` を高速化できます。
- **注意**: `v.size()` は `size_t` なので、`v.size() - 1` のような計算はアンダーフローに注意が必要です。

### [2] 集合・連想配列 (set, map, multiset)
- **鉄則**: `multiset` で特定の値を1つだけ消したい場合は、`st.erase(st.find(x))` と書きます（`st.erase(x)` だと全削除されます）。
- **発展**: `unordered_set/map` は平均 $O(1)$ ですが、ハッシュ衝突による最悪 $O(N)$ のリスクがあることを念頭に置いてください。

### [3] コンテナアダプタ (stack, queue, priority_queue)
- **鉄則**: これらには `.clear()` がありません。空にするには `q = queue<int>();` のように再代入します。

### [4] bitset
- **メリット**: ビット演算による高速化により、通常のループ処理を約64倍高速化できます（定数倍高速化）。

## 3. 使い方
VS Code で `cp` と入力して補完を確定させてください。
コードの末尾にコメントとしてチートシートが挿入されるため、コンテスト中にいつでも計算量やメンバ関数を確認できます。
