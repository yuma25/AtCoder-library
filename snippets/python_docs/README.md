# Python 最強スニペット解説 (pycp)

このドキュメントでは、`snippets/Pythonスニペット.json` に登録されている `pycp` スニペットの詳細と、Python で競技プログラミングを戦うための鉄則を解説します。

## 1. テンプレートの構成
- **再帰上限の引き上げ**: `sys.setrecursionlimit` を設定済み。深い DFS も安心です。
- **入出力高速化**: `sys.stdin.readline` を `input` として定義。`I()`, `MI()`, `LI()` で高速に入力を取得できます。
- **便利関数**: `chmax`, `chmin` (Python は値渡しのため、`a = chmax(a, b)` と代入して使います)。
- **数学ライブラリ**: `Combination` クラスにより nCr を $O(1)$ で計算（要事前計算）。

## 2. 競技プログラミングの鉄則・チートシート
末尾のコメントに含まれるチートシートのハイライトです。

### [1] リスト・文字列
- **鉄則**: 先頭の削除 (`pop(0)`) は $O(N)$ かかります。頻繁に行う場合は `collections.deque` を使いましょう。
- **テクニック**: `A[::-1]` で反転したコピーを作成できます。

### [2] 辞書・集合 (dict, set)
- **特徴**: Python の辞書と集合は非常に強力で、平均 $O(1)$ で動作します。
- **便利**: `collections.Counter` を使うと、要素の出現回数を一瞬で集計できます。

### [3] 優先度付きキュー (heapq)
- **鉄則**: `heapq` は常に**最小値**を取り出します。最大値を取り出したい場合は、要素に `-1` を掛けて格納します。

### [4] 二分探索 (bisect)
- **対応**: `bisect_left` が C++ の `lower_bound`、`bisect_right` が `upper_bound` に相当します。

## 3. 使い方
VS Code で `pycp` と入力して補完を確定させてください。
コンテスト中に迷いやすい「あの関数の計算量は？」「このライブラリはどうインポートする？」といった疑問が、コード末尾のチートシートですぐに解決します。
